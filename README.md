# CODSOFT_TASK-1
CodSoft Internship Tasks

      📝 To-Do List Application

A simple To-Do List desktop application built using Python and Tkinter. It allows users to add, delete, complete, and clear tasks through an easy-to-use graphical interface.

✨ Features

- ➕ Add new tasks
- 🗑️ Delete selected tasks
- ✅ Mark tasks as completed
- 🧹 Clear all tasks
- ❌ Exit confirmation
- ⚠️ Warning messages for invalid actions

🛠️ Technologies Used

- Python
- Tkinter
- MessageBox

🚀 How to Run

1. Install Python.
2. Save the code as:
   "ToDo_List.py"
3. Open the terminal in the project folder.
4. Run:

python To-Do list.py

📌 Project Purpose

This project was created to practice Python GUI development using Tkinter, including buttons, labels, entry fields, listboxes, frames, and message boxes.
